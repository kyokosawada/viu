# Viu

A mobile client for a [herdr](https://herdr.dev) agent fleet.

See your panes, open an agent, read what it said, and answer it - by voice or keyboard - from your phone.

Viu talks to a small JSON bridge on the host machine over [Tailscale](https://tailscale.com). It is not an SSH client and not a terminal emulator.

## Status

Early. The stack is not chosen yet.
