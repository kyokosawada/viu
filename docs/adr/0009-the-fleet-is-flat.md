# The fleet is one flat list

herdr nests panes inside tabs inside workspaces. Viu discards that hierarchy and shows a single list
of panes ordered by who needs you, labelled by project.

The hierarchy is furniture for a desktop terminal manager with a sidebar. The question a person
opens Viu to answer is "which agent needs me", and that ordering cuts straight across workspaces and
tabs. A three-level tree costs two taps before it tells you anything.

Viu also shows every pane the herdr server knows about rather than scoping to one named session.
Filtering is a view concern on the phone, not a boundary baked into the protocol.

## Consequences

If work is ever deliberately organised into several workspaces, the phone will have thrown that
structure away, and recovering it means reintroducing a grouping concept. Accepted on the basis that
the fleet is currently one workspace and the sort order carries more value than the tree.
