# Dictation is English only

Viu dictates using the on-device en-US engine. Offline, private, and no cloud recogniser.

The owner speaks English to their agents. The Android on-device engine's weak Filipino, Tagalog and
en-PH coverage was raised as a possible gap and ruled irrelevant on that basis.

## Consequences

Do not reintroduce a cloud speech recogniser for language coverage - it would trade the offline and
private properties for a gap that does not exist in practice. Dictated words are always shown before
anything is sent, and hold-to-talk ends capture on release without sending.
